# 🎬 Sentiment Analysis Model

## VORTEXTECH AI & ML Internship — Week 4

A Natural Language Processing (NLP) project that classifies IMDB movie reviews as **Positive** or **Negative** using **TF-IDF** and **Logistic Regression**.

## 🎯 Objective

Build a machine learning model that:
- Processes and cleans text data
- Converts text into numerical features using TF-IDF
- Classifies reviews as positive or negative
- Evaluates performance using Accuracy and F1-score
- Predicts sentiment for new sentences

## 📊 Dataset

**IMDB Movie Reviews Dataset**

- ~50,000 movie reviews
- Columns: `review`, `sentiment`
- Labels: `positive` and `negative`

## 🛠️ Technologies

- Python
- Pandas & NumPy
- Scikit-learn
- Matplotlib & Seaborn
- Jupyter Notebook
